# Security and privacy checklist

- Obtain informed consent and explain location tracking start/stop.
- Request only necessary location permissions and disclose background use.
- Never collect/store biometric templates.
- Enforce role access in rules and trusted backend functions.
- Restrict employees to own records; managers/supervisors to assigned teams.
- Validate uploads by path, size and content type.
- Audit approvals, role/device changes and attendance corrections.
- Consider Firebase App Check, backups, retention and incident response.
- Keep credentials and signing keys outside source control.
- Conduct privacy/security review before field rollout.
