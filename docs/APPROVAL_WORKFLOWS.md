# Approval workflows

Registration: employee submits → pending → HR/Admin approves or rejects → trusted backend assigns role/access.

Device change: employee requests → HR/Admin reviews → old device revoked according to policy.

Leave route proposed: Employee → Manager → HR → Admin.

**Must be confirmed before implementation:** Does the request complete as soon as two of the three approvers approve? Does one rejection block it? Can Admin override a rejection? Are approvals sequential or parallel? Do not assume these rules.
